# 实验报告证据规则

维护实际实验、训练、调优或评估报告时读取；普通 README、开发记录不需要套用实验结构。领域字段、指标和报告布局服从项目规范。

- 说明实验目的、方法、数据与划分、比较条件、指标定义、运行来源、结果和有限结论。记录影响结果的数据处理、样本筛选、排除条件和覆盖率，保留失败、负面及未完成状态。
- 优先依据运行保存的结果、配置、日志、代码快照和 checkpoint 元信息。可变仓库配置仅描述当前设置，不能证明历史运行条件。来源缺失时标记未知，不补造版本、日期或提交。
- 日期按项目定义；未规定时明确区分启动、结束、评估和修订日期，避免一个含糊日期替代多个事件。版本保留完整原值，推断值明确写出依据。
- 指标说明单位、方向、聚合方式、样本范围及不确定性（如适用）。均值、标准差、均方误差等不能互相替代；换算须给出有依据的公式、单位和输入。近似值不与实测值混写。
- 比较结果需核对数据、划分、预处理、模型或系统版本及评估协议。多个条件同时变化时不能断言单变量因果；不同口径不能直接排名。
- 调参选择遵循实际 objective 和完成状态，不能将运行中结果当最终排名，或将观察到的最佳结果声称为全局最优。重复运行和筛选规则应披露。
- 汇总表由项目需要决定，不强制固定列；每行明确对应条件或子集，详细证据通过链接引用。关键指标、样本数、状态和来源与正文一致。
- 更正历史结果时保留修订日期、依据、影响与原口径的可追溯关系；迁移不能改变原实验结论。完整性校验与独立复算保留为结果证据。
